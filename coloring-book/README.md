# Unicorn Coloring Book (For Kids Ages 4-8): ready to publish

An original unicorn coloring book with 40 single-sided designs. It is print-ready for
**Amazon KDP** (paperback, 8.5 x 11 in) and also works as a printable PDF you can sell on Etsy.

All artwork is drawn from scratch by `art.py` and `generate.py`. No clip art or third-party images are used.

## Files (`output/`)

| File | Use |
|---|---|
| `interior.pdf` | Upload as the **manuscript**. 84 pages, 8.5 x 11 in, no bleed. |
| `cover.pdf` | Upload as the **cover**. Full wrap, 17.439 x 11.25 in (0.125 in bleed, 0.189 in spine for white paper). |
| `cover-front.png` | Front cover image for social media, Etsy or mock-ups. |
| `preview-*.png` | Sample inside pages for your listing or "Look inside" images. |

Page order: "This book belongs to", a "test your colors" page, 40 designs (each followed by a
blank back so markers don't bleed through), then a "Well done" page and a blank page.

## Customize and rebuild

```bash
pip install cairosvg pypdf pillow
python3 generate.py
```

Settings are at the top of `generate.py`:
- `AUTHOR`: replace "Rainbow Pencil Press" with your own pen name or brand.
- `N_DESIGNS`: the number of designs. The cover spine width is recalculated automatically.
  If you change the page count, use the new `cover.pdf`.
- `PAL`: the cover colors.

## Publishing on Amazon KDP (kdp.amazon.com)

1. **Paperback details**
   - Language: English
   - Title: `Unicorn Coloring Book`
   - Subtitle: `For Kids Ages 4-8: 40 Cute Unicorn Designs with Rainbows, Castles and Stars`
   - Author: your pen name (use the same name as `AUTHOR`)
   - Reading age: 4-8
   - Categories: *Children's Books > Activities, Crafts & Games > Coloring*, and
     *Children's Books > Animals > Horses*
   - Keywords (7 boxes): `unicorn coloring book for girls`, `coloring books for kids ages 4-8`,
     `unicorn gifts for girls`, `activity book for kids`, `rainbow coloring pages`,
     `toddler coloring book ages 2-4`, `unicorn birthday gift`
2. **Content**
   - Print ISBN: free KDP ISBN
   - Interior: black & white, white paper
   - Trim: 8.5 x 11 in, **no bleed**, matte cover
   - Upload `interior.pdf` and `cover.pdf`, then check everything in the Previewer.
   - **AI-generated content question:** this artwork was generated by code with an AI assistant.
     Answer KDP's AI-content question truthfully, following their current definitions.
3. **Pricing**: $6.99-7.99 (about 7.99-10.54 EUR on Amazon.fr; the book you showed sells for 10.54 EUR).
   An 84-page B&W book costs about $1.90 to print, so you earn roughly $2-2.50 per sale at 60% royalty.
   Choose worldwide distribution so it also sells on Amazon.fr, .de, .co.uk and others.

## Ideas for a series

The reference book is "Book 1 of 12". You can reuse the same code for a series: change the palette
and title, swap `unicorn()` for another animal, or raise `N_DESIGNS` to 50 and publish volume 2.
